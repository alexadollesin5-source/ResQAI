# ResQAI Admin Website

A responsive multi-page front-end prototype for the ResQAI disaster evacuation and emergency assistance system. Each admin area opens as its own page instead of stacking every section into one long screen.

## Open in Visual Studio Code
1. Extract the ZIP file.
2. In VS Code, choose **File → Open Folder** and select `ResQAI_Admin_VSCode`.
3. Install the **Live Server** extension if it is not installed.
4. Right-click `index.html` and select **Open with Live Server**.
5. Use the sidebar to open Dashboard, Emergency Reports, Evacuation Centers, Assistance Requests, Evacuee Records, and Announcements.

## Files
- `index.html` — dashboard
- `reports.html` — emergency reports and AI-assisted summaries
- `centers.html` — evacuation center occupancy and availability
- `requests.html` — assistance request status management
- `evacuees.html` — evacuee records
- `announcements.html` — public information drafts
- `styles.css` — shared responsive design
- `script.js` — demo interactions

## Prototype limitations
All records are sample data. This is a front-end prototype only: login, database persistence, live maps/GPS, and actual AI/Gemini report analysis are not connected. AI summaries shown are examples and must not be used for real emergency decisions.
